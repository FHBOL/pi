# 安全

Pi 是本地编程 agent。它以启动它的用户账户的权限运行，并将该用户可写的文件视为同一本地信任边界内。

## 项目信任

项目信任控制 pi 是否加载项目本地的设置、资源、包与扩展。它不是沙箱，也不会在你开始在某目录工作时限制模型能让工具做什么。

当 Pi 从当前工作目录发现以下任一内容时，会认为该项目有需要信任的资源：

- `.pi/settings.json`
- `.pi/extensions`、`.pi/skills`、`.pi/prompts` 或 `.pi/themes`
- `.pi/SYSTEM.md` 或 `.pi/APPEND_SYSTEM.md`
- 当前目录或祖先目录中的项目 `.agents/skills`

仅有空的 `.pi` 目录不算需要信任的项目资源。

当交互会话在带有需信任资源的项目中启动，且当前目录或父目录没有已保存决策时，pi 会遵循全局设置中的 `defaultProjectTrust`。默认值为 `"ask"`，在有 UI 时会询问是否信任该项目。已保存决策按规范目录路径存于 `~/.pi/agent/trust.json`，当前或父路径上最近的已保存决策会先于全局默认值生效。

信任项目后，pi 可加载需要信任的项目资源，包括：

- `.pi/settings.json`
- `.pi` 资源，如扩展、skills、提示模板、主题与系统提示文件
- 通过项目设置配置的、缺失的项目包
- 项目本地扩展与由项目包管理的扩展

拒绝信任会跳过受保护资源。诸如 `AGENTS.override.md`、`AGENTS.md` 和 `CLAUDE.md` 的上下文文件会在项目信任之外照常加载（除非禁用了上下文加载）。在信任解析完成前，pi 仅加载上下文文件、用户/全局扩展以及 CLI `-e` 扩展。用户/全局与 CLI 扩展可处理 `project_trust` 事件；第一个返回是/否决策的扩展拥有该决策。

非交互模式（`-p`、`--mode json` 与 `--mode rpc`）不会显示信任提示。在没有适用的已保存信任决策时，`defaultProjectTrust: "ask"` 与 `"never"` 会忽略此类资源，而 `"always"` 会信任它们。使用 `--approve`/`-a` 或 `--no-approve`/`-na` 可覆盖单次运行的项目信任。

## 无内置沙箱

Pi 不包含内置沙箱。内置工具可以读取、写入、编辑文件，并以 pi 进程的权限运行 shell 命令。扩展是以相同权限运行的 TypeScript 模块。包安装、shell 命令、语言服务器、测试命令以及其他开发工具都表现为普通本地进程。

这是有意为之。Pi 设计用于操作本地源码树、调用项目工具链，并与用户现有的开发环境集成。进程内的半吊子沙箱很容易被误认为安全边界，却仍依赖宿主机 shell、文件系统、包管理器、凭证与扩展代码。真正的隔离需要来自操作系统或虚拟化/容器边界。

项目信任只是输入加载守卫。它防止仓库在你批准前静默更改 pi 的设置或扩展。它不能让不受信任的代码、不受信任的提示或不受信任的模型输出变得安全。来自仓库文件、注释、文档、上下文文件或构建输出的提示注入，是本地 agent 的预期风险，pi 无法可靠地阻止。

## 运行不受信任或无人值守的工作

对于不受信任的仓库、你不打算密切监控的生成代码，或无人值守自动化，请在受控环境中运行 pi。使用容器、VM、微 VM、远程沙箱或策略控制的沙箱，且仅提供任务所需的文件与凭证。

常见模式见 [容器化](containerization.md)：

- 将整个 `pi` 进程放在容器/沙箱内运行
- 在宿主机运行 pi，同时将内置工具执行路由到 Gondolin 微 VM
- 仅挂载 agent 应访问的工作区路径
- 除非容器需要访问宿主机会话、设置与凭证，否则避免挂载宿主机 `~/.pi/agent`
- 传入最少必要的 API 密钥，或使用短期凭证
- 任务不需要网络时限制网络访问
- 在将结果复制回受信任系统前审查 diff 与输出

若以读写方式绑定挂载宿主机工作区，容器或 VM 内的写入仍可修改宿主机文件。需要更强防止意外写入时，请使用只读挂载，或将文件复制进/出沙箱。

## 报告安全问题

要报告安全问题，请遵循仓库的 [安全策略](https://github.com/earendil-works/pi-mono/blob/main/SECURITY.md)。请勿为涉及安全敏感的报告开公开 issue。

本地 agent 的预期行为、缺少内置沙箱、来自不受信任内容的提示注入，以及用户安装的扩展或 skills 的行为，一般不在安全边界内，除非报告证明了真实的权限边界绕过，或说明 pi 授予了本地用户原本没有的访问权。
